About Flight Reservation System

Project Overview


The Flight Reservation System is a web-based application designed to simplify flight searching, passenger registration, flight booking and reservation management.


Data Structures Used


  • Array: Stores flight and passenger records.
  • Objects: Stores individual flight and booking information.
  • Searching: Searches flights based on source and destination.
  • Sorting: Sorts flights according to fare and seat availability.
  • Queue: Waiting-list concept for unavailable seats.

Technologies


HTML5, CSS3 and JavaScript
